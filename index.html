⚙️ DETAIL SPESIFIKASI KOMPONEN HARDWARE & INFRASTRUKTUR IOT

Sistem Smart Green House dibangun menggunakan arsitektur mikrokontroler ESP32 terintegrasi dengan berbagai sensor presisi tinggi, aktuator relay, serta komunikasi data cloud secara real-time.

🧠 ESP32 Microcontroller Otak Utama
• Fungsi: Pemroses data utama dan modul Wi-Fi/Bluetooth.
• Fitur: Dual-core 240MHz, mendukung komunikasi MQTT, HTTP GET untuk Google Sheets, serta integrasi Bot Telegram API.
🌡️ Sensor DHT11 / DHT22 Sensor Lingkungan
• Fungsi: Membaca suhu (°C) dan kelembaban udara (%) di dalam ruang green house.
• Pin ESP32: Pin Digital 4.
• Sifat: Memberikan pemicu otomatis untuk mengaktifkan kipas pendingin.
🌱 Soil Moisture Sensor Sensor Tanah
• Fungsi: Mengukur tingkat kadar air/kelembaban pada media tanam tanah.
• Pin ESP32: Pin Analog 34 (ADC).
• Sifat: Menentukan pemicu penyiraman otomatis oleh pompa air utama.
⚡ Modul Relay 4-Channel Aktuator Saklar
• Fungsi: Saklar elektronik pengontrol arus AC/DC beban tinggi.
• Channel 1 (Pin 25): Pompa Air Utama.
• Channel 2 (Pin 26): Pompa Dosis Nutrisi Pupuk.
• Channel 3 (Pin 27): Kipas Exhauster / Cooling.
📺 LCD 16x2 I2C Display Display Lokal
• Fungsi: Menampilkan informasi nilai sensor dan status relay secara fisik di lokasi Green House.
• Komunikasi: I2C Bus (SDA Pin 21, SCL Pin 22) dua halaman auto-switch.
🚰 Pompa Air Mini Submersible Output Fisik
• Pompa Air: Menyuplai irigasi air dan nutrisi pupuk cair secara otomatis ke media tanam.
• Spesifikasi: Mini Submersible Pump DC 3V-6V.
